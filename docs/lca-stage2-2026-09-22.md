## 2. 실행 중 발견해 고친 것 (모두 실 모델 e2e에서만 드러남)

1. **스냅샷이 플러그인 자체 상태를 diff에 포함**: `.lca/state/sessions/*/session.json`이 태스크 변경분으로 잡혀 리뷰어가 "범위 밖 파일 변경"으로 REJECT. 스냅샷 pathspec에서 `.lca`를 항상 제외.
2. **테스트 실행 생성물이 diff에 포함**: 워커가 pytest를 돌리며 만든 `__pycache__/*.pyc`도 같은 이유로 REJECT. `delegate.diff_exclude`(기본 `__pycache__`, `.pytest_cache`, `node_modules`, `.venv`, `*.pyc` 등, 깊이 무관)로 제외.
3. **재시도가 빈 diff로 다시 거부됨**: 1차 시도가 이미 작업을 끝낸 뒤 REJECT되면 2차 워커는 바꿀 게 없어 diff가 비고 리뷰어가 또 REJECT. 스냅샷을 태스크당 1회(첫 시도 전)만 찍어 재시도는 누적 diff로 판정.
4. **`opencode run "ulw: ..."`가 셸 따옴표를 그대로 전달**: 사용자 메시지가 `"ulw: ..."`처럼 큰따옴표로 감싸여 도착하고, 인용문을 감지에서 제외하는 sanitizer가 메시지 전체를 인용으로 취급해 모드가 켜지지 않음(2차 실행: main이 위임 없이 35초 만에 직접 구현, 원장 없음). 메시지 전체가 한 쌍의 따옴표로 감싸인 경우만 한 겹 벗긴 뒤 감지(`unwrapWholeQuote`). 1단계에서는 모드 없는 fib 과제만 돌려 드러나지 않았음.
5. **자식 세션 thinking OFF가 실제로는 무시됨**: `chat.params`의 `output.options`는 AI SDK providerOptions가 되므로 키가 camelCase `reasoningEffort`여야 하는데 1단계 훅이 `reasoning_effort`를 넣어 무시되고 있었음(모든 워커·리뷰어 세션에 reasoning 파트 존재, 리뷰어 3은 생각만 하다 출력 상한 도달). 사용자 설정의 `options.reasoningEffort`와 같은 키로 수정. 4차 실행에서 검증: 자식 세션 6개 모두 reasoning 파트 0개, 리뷰어 3건 전부 ACCEPT, 벽시계 183초 → 76초.

## 3. 구조 (2단계 추가분)

```
framework/src
├── state/ledger.ts            원장 타입·원자적 읽기/쓰기·addTasks/nextPending/fingerprint, handoff 파일(10~20줄)·handoffContext(≤600자)·summarizeLedger
├── orchestration/queue.ts     직렬 큐: 스냅샷 → worker 자식 세션(session.create+prompt 블로킹) → diff → verify 명령(코드 실행) → reviewer 게이트 → 원장/handoff
├── orchestration/snapshot.ts  임시 GIT_INDEX_FILE로 워킹트리 tree 해시(.lca·생성물 제외), tree 간 diff. 사용자 인덱스/HEAD 불변
├── orchestration/shell.ts     verify 명령 실행(타임아웃, 출력 tail), git 래퍼
├── tools/delegate.ts          main 전용 툴. 원장에 추가 후 큐를 툴 호출 안에서 완주, 결과 1개 요약 반환. abort 신호 → 큐 중단
├── hooks/command.ts           /stop: abort.json + 모드 해제 + 실행 중 자식 세션 abort → 남은(또는 미실행 중 열린) 태스크 cancelled
├── orchestration/gaming.ts    (2차 리뷰) 태스크 텍스트의 회피 지시 거부, diff 추가 줄의 해킹 패턴 스캔
└── loop/idle.ts               (2차 리뷰 후) 큐를 실행하지 않음. 중단된 실행의 미완료 태스크가 있으면 main에 "delegate resume:true" 안내를 1회 주입(chat.message도 사용자 다음 메시지에 첨부); ulw 활성이면 1단계 todo 루프
$XDG_STATE_HOME/lca/<repo-hash>/sessions/<main>/ledger.json   제어면(단일 writer, 워크트리 밖)      .lca/handoffs/<main>/task-<n>.md   데이터면
scripts/fixtures/ulw3/, ulw-fail/       circle/rect/triangle 3모듈 + 테스트 3개 / 불가능 단언 부정 케이스
scripts/lca-e2e.sh --fixture ulw3        E05~E14 판정, 원장/handoff를 logs/로 복사
scripts/lca-doctor.sh D09a~c, D10        /stop 등록, `debug agent` 실측 툴 가시성(OMO 공존 시 FAIL), delegate 스키마 ≤400 토큰(실측 ~257), chat.params 옵션 키
```

설계 결정:
- **블로킹 delegate**: 내장 `task` 툴과 같은 모양(툴 호출 1번 = 목록 전체). 약한 모델이 호출 1번만 하면 되고, 원장·핸드오프·판정이 전부 코드에 있어 모델 출력 텍스트를 파싱하지 않는다(리뷰어의 마지막 줄 ACCEPT/REJECT와 워커 보고의 `Open issues:` 줄만 예외이며 이는 각 에이전트의 출력 계약). 큐는 오직 툴 호출 안에서만 돌고, 중단된 실행은 main에 "resume:true" 안내를 1회 주어 다시 툴 호출로 재개한다(2차 리뷰 반영).
- **캐시**: 자식 세션이 GPU 슬롯을 쓰는 동안 main은 툴 결과를 기다릴 뿐 프리필이 없다. 3차 실측에서 main 캐시 미스 1회, 자식 6세션 미스 2회.
- **검증은 코드가**: 워커 보고서의 "Verification:"은 믿지 않고 태스크의 `verify` 명령을 프레임워크가 직접 실행해 결과를 원장·리뷰어·재시도 사유에 쓴다.
- **ulw 모드 의미 변경**: 접미 지시가 "직접 하지 말고 delegate를 1번 호출하라"로 바뀜. 직접 작업은 키워드 없이.

## 4. 확인된 OpenCode 동작 (1.18.32, 코드·실행으로 검증)

- 플러그인 `client`는 서버 프로세스 내부 `fetch`(`Server.Default().app.fetch`)라 툴 실행 중 `session.create`/`session.prompt`(블로킹)를 호출해도 교착이 없다. 자식 세션은 `parentID`로 만들어 baseline 스크립트가 부모-자식으로 집계한다.
- 플러그인 `tool` 훅의 툴은 모든 에이전트에 노출되므로 worker/reviewer/build/plan은 `permission.delegate="deny"`로 숨긴다(에이전트 `tools` 키는 플러그인 훅 시점엔 무시됨, 7.1 F1). 툴 스키마 = 프리픽스.
- `chat.message`는 자식 세션에도 호출된다(`input.agent`=worker/reviewer). 모드 감지는 main에만 적용.
- `opencode run --agent <subagent>`는 subagent 모드 에이전트를 무시하고 main으로 실행한다(리뷰어 단독 프로브 불가).
- `command.execute.before`는 `{command, sessionID, arguments}`를 받고, 템플릿 텍스트는 그대로 사용자 메시지로 모델에 간다(`/stop` 템플릿을 cancel 키워드로 작성).

### 8.3 남은 약점 (정직한 평가)

- 패턴에 걸리지 않는 회피(예: 결과를 파일에 캐시)는 코드로 못 잡는다. 리뷰어는 26B·thinking OFF에서 약하므로 **verify 명령과 보호 파일이 실제 게이트**다. 태스크별 테스트를 쓰고, 불가능한 테스트는 코드와 무관한 단언(`assert 1 == 2`)으로 만들어야 회피가 불가능하다.
- 리뷰어 "4질문+판정 마지막 줄" 형식은 회피 diff에 대해 아직 실 모델로 검증되지 않았다(회피 diff가 이제 코드 단계에서 거부되어 리뷰어까지 오지 않기 때문).
- TUI Esc×2 경로는 2026-09-23 실측 완료(위 5절). 프로세스 간 큐 락, 헤드리스 배치 원장은 미구현.
